# Justin M. Daniels Portfolio

This is a self-contained, responsive HTML/CSS/JavaScript portfolio based on the approved dark studio-style mockup.

## Edit the portfolio

1. Open `index.html` in a browser to preview it.
2. Open `index.html` in a text editor (VS Code, Cursor, Sublime Text, etc.).
3. Search for the placeholder text you want to change.
4. Replace `YOUR-EMAIL@example.com` with your actual email.
5. Replace the visual placeholders with your actual project images/video embeds when ready.
6. Edit colors and typography in `styles.css` using the variables at the top.

## Publishing

The site is plain HTML/CSS/JS, so it can be hosted on GitHub Pages, Netlify, Vercel, or almost any standard web host without a CMS.

## Important

The site currently uses a Google Fonts import. If you want a completely self-contained/offline version, download the fonts and update the CSS font-face rules.
